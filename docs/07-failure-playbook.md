# 失败手册

## 登录 / 认证

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫码后一直不跳转 | 登录态未保存 | 重跑；确认 `SAVE_LOGIN_STATE=True` |
| 抖音提示手机号验证 | 风控 | 在弹出的浏览器里人工完成 |
| 小红书详情为空 | 缺 `xsec_token` / 未登录 | 从搜索结果进入详情；重新登录 |
| X 返回 401/403 | Cookie 过期 | 重新提取 `auth_token` / `ct0` |
| 微博评论为空 | 游客态限制 | 登录后重跑 |

## 验证码

| 平台 | 现象 | 处理 |
|---|---|---|
| 微信公众号 | 搜狗 antispider | 在浏览器窗口手动点选，脚本会等待 |
| 小红书 | 滑块 | 手动完成；降低频率 |
| 抖音 | 验证码 | 手动完成 |

不要尝试自动绕过验证码。

## 空结果

| 现象 | 排查 |
|---|---|
| 搜索 0 条 | 关键词太窄；换同义词；检查时间窗 |
| 有帖子无评论 | 用 detail 模式补抓；确认评论接口返回 |
| 评论覆盖低 | 检查平台报告的评论数；对高评论帖优先补抓 |
| 时间大量缺失 | 检查字段名与时间格式；相对时间需要抓取时间兜底 |

## 视频

| 现象 | 处理 |
|---|---|
| 下载失败 | 换 `yt-dlp` 最新版；检查代理 |
| X 视频 403 | 用推文 URL 下载，不要用过期 CDN 直链 |
| 无字幕 | 回退 Whisper |
| 转写错字多 | 换更大模型；注入领域词；人工抽查 |
| 长视频超时 | 分段转写；按段落送 LLM |
| 画面为主、口播少 | 进人工复核；OCR 接口预留 |

## 数据质量

| 现象 | 处理 |
|---|---|
| 重复率高 | 检查补抓是否重复写入；确认去重键 |
| 相关性误判 | 调整 `keywords.exclude`；检查评论继承 |
| 评论挂错父帖 | 检查 `parent_id` 字段映射 |
| 时间越界 | 检查时区与毫秒/秒转换 |

## 审计失败

```bash
.venv/bin/python -m pipeline.audit --strict
```

按 `data/reports/audit.md` 的建议逐条处理，不要跳过。
